## Known gaps

- The catalog descriptions, API docs, MCP, AI output and platform names stay English by design (spec v3 §5).
- Month and weekday names come from `Intl`; numbers follow the project's decimal setting.
- Content typed or chosen by the agency stays as typed: report titles, block titles, the default templates' section
  names ("Paid media", "Social media", …), timeline events and analysis cards (AI output is not translated).
- The per-platform "About these numbers" sentences (`src/lib/catalog/data-notes.ts`) are catalog text and stay English;
  only the generic sentence on the client page is translated.
- The metric picker in the widget settings (MetricSelect) shows the catalog's English titles: its items carry no
  reference key, so the label map cannot be applied there.
- The per-integration setup help on the connect page (`HELP` in `src/app/projects/[id]/connect/[slug]/page.tsx`: where to
  find a token, env-var names, URL formats), the OAuth provider names and account nouns ("ad accounts", "properties"),
  the overview anomaly metric names ("Meta spend", "Sessions", "Google Ads spend") and the browser-tab page titles stay
  English (technical setup text and platform terms).
- The per-platform "About these numbers" sentences now have a Greek copy in `src/lib/catalog/data-notes.ts`
  (`DATA_NOTES_EL`, listed below for review).
