# v3 Plan H — Greek (app, client pages, e-mails, metric labels)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The agency UI, the client-facing chrome of public pages, e-mails and the PDF chrome in Greek, chosen per company with a per-user override, plus Greek labels for the 60 most used metrics; metric names otherwise stay as the platforms name them.

**Architecture:** Flat dictionaries (`en.ts`, `el.ts`) with namespaced keys; a server `t()` plus a client `I18nProvider`/`useT()` that ships only the namespaces a page needs; locale resolution user → company → browser, and project locale (with `?lang=`) on public pages; a parity test and a check script keep the two dictionaries aligned. Strings are extracted area by area so each task leaves a working app.

**Tech Stack:** as plan D. `Intl.DateTimeFormat` for month/weekday names.

**Spec:** `docs/superpowers/specs/2026-10-22-v3-programme-design.md` §5.

## Global Constraints

- Ledger: `.superpowers/sdd/2026-10-22-v3-h-greek/progress.md`; checkpoints instead of commits; demo untouched.
- Locales: `en`, `el`; keys namespaced `area.item` (`nav.overview`, `editor.addBlock`, `public.sources`, `email.held.subject`); interpolation `{name}`; fallback `el → en → key` (never the bare key in production: log once in development).
- Precedence: `User.locale` → `Company.locale` (default `en`) → `Accept-Language` starting with `el` → `en`; public pages: `?lang=el|en` → `Project.locale`.
- Public pages ship only `public.*` strings (≤ 8 kB); the public report First Load JS stays ≤ 110 kB.
- Not translated: catalog descriptions, API docs, MCP, AI output, platform names, metric names outside the 60-label list.
- Glossary (fixed): report = αναφορά, dashboard = πίνακας, goal = στόχος, automation = αυτοματισμός, milestone = ορόσημο, integration = σύνδεση, campaign = καμπάνια, conversions = μετατροπές, spend = δαπάνη, template = πρότυπο, client = πελάτης, period = περίοδος, comparison = σύγκριση.
- `docs/i18n-review.md` lists every key with EN and EL for a native reviewer; the Greek is a draft until reviewed.

## Review Focus

- A key present in `en` but missing in `el`: the English string renders and the parity test fails — pinned by Task 1 and Task 6.
- A client-role user whose company is Greek but who set `User.locale = 'en'`: the app is English for them, their public links follow the project — pinned by Task 1.
- `?lang=fr` on a public page: falls back to the project locale, no error — pinned by Task 4.
- Dates on a Greek public cover: month names in Greek through `Intl`, numbers unchanged (project decimal setting) — pinned by Task 4.
- A metric without a Greek label on a Greek page: the English catalog title shows, never an empty label — pinned by Task 5.
